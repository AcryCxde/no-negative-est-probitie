# Описание API

> Снимок страницы <https://hackathon.no-offence.ru/documentation> (`Battleships.mhtml`, 2026-10-10). Платформа может менять правила: источник истины — страница и `MATCH_STARTED` партии.

Ответ любого метода — `{"value": …, "error": …}`. Методы вызываются с сессией вошедшего пользователя.

## Боты команды

### POST /api/v1/teams/current/bots

Добавление бота

Заводит бота с именем, своим токеном и стартовым рейтингом; у команды не больше 3 ботов

#### Тело запроса

| Поле | Тип | Описание |
|---|---|---|
| `name` | string | Имя бота: от 1 до 32 символов без пробелов по краям и двух пробелов подряд, буквы одного алфавита — латиницы или кириллицы, цифры, пробел и знаки «-», «_», «.»; проверяется и сохраняется в форме NFKC, уникальное среди ботов команды без учёта регистра |

#### Ответ

| Поле | Тип | Описание |
|---|---|---|
| `id` | string (uuid) | Идентификатор бота |
| `name` | string | Имя бота, уникальное среди ботов команды без учёта регистра |
| `token` | string | Текущий токен бота, с которым он подключается к платформе |
| `presence` | BotPresence | Состояние бота: не в сети, в сети и свободен, в сети и играет матч, заблокирован |
| `mode` | BotMode, может быть null | Режим бота, пока он в сети; null — бот не в сети или заблокирован |
| `bonuses` | object[] | Число использований каждого бонуса, заданное командой: все бонусы, в порядке перечисления Bonus; 0 — бонуса у бота нет. Действует в пределах лимита администратора на старте матча |
| ↳ `bonus` | Bonus | Бонус |
| ↳ `uses` | integer | Число использований |
| `achievements` | object[] | Ачивки бота в порядке каталога; переходящая — только у её владельца |
| ↳ `achievement` | Achievement | Ачивка |
| ↳ `level` | integer, может быть null | Уровень ачивки со ступенями: 1, 2 или 3; null у остальных |
| ↳ `value` | integer, может быть null | Значение показателя у владельца переходящей ачивки — длина серии, число выстрелов или число побед; null у остальных |

#### Ошибки

| HTTP | Код ошибки | Смысл |
|---|---|---|
| 401 | UNAUTHORIZED | Нет сессии: путь доступен только после входа |
| 403 | FORBIDDEN | Роль сессии не допускает этот метод, или изменяющий запрос браузер отправил со страницы другого сайта |
| 400 | BAD_REQUEST | Запрос отклонён Spring MVC: неверный метод, тип содержимого, параметры или тело |
| 400 | NAME_CHARACTERS_INVALID | Имя команды или бота содержит недопустимые символы: допустимы буквы одного алфавита — латиницы или кириллицы, цифры, пробел и знаки «-», «_», «.» |
| 409 | BOT_LIMIT_REACHED | У команды уже максимальное число ботов |
| 409 | BOT_NAME_TAKEN | Имя бота совпадает с именем другого бота команды без учёта регистра |

### PUT /api/v1/teams/current/bots/{botId}/bonuses

Бонусы бота

Задаёт боту число использований названных бонусов в матче, не названные не меняются. Число — от 0 до текущего лимита администратора; включение бонуса и общий выключатель сохранению не мешают. Сохранённое число остаётся, даже если администратор потом снизил лимит: на старте матча берётся меньшее из числа команды и лимита. Бонус, названный дважды, или отрицательное либо нецелое число — отказ, бонусы бота прежние

#### Параметры пути

| Поле | Тип | Описание |
|---|---|---|
| `botId` | string (uuid) | Идентификатор бота команды текущей сессии |

#### Тело запроса

| Поле | Тип | Описание |
|---|---|---|
| `bonuses` | object[] | Бонусы с новым числом использований, каждый бонус не больше одного раза |
| ↳ `bonus` | Bonus | Бонус |
| ↳ `uses` | number | Число использований бонуса в матче: целое число от 0 до текущего лимита администратора; 0 — бонуса у бота нет |

#### Ответ
