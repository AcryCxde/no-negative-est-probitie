# Значения и причины

> Снимок страницы <https://hackathon.no-offence.ru/documentation> (`Battleships.mhtml`, 2026-10-10). Платформа может менять правила: источник истины — страница и `MATCH_STARTED` партии.

### Закрытие соединения

| Код | Значение | Смысл |
|---|---|---|
| 4001 | TOKEN_REISSUED | Команда перевыпустила токен, с которым открыто это соединение |
| 4002 | CONNECTION_REPLACED | Открыто новое соединение с этим токеном |
| 4003 | DELIVERY_FAILED | Сообщения боту не доставлены: очередь переполнена или отправка не уложилась в срок |
| 4004 | BOT_BLOCKED | Администратор заблокировал бота |
| 4005 | BOT_DELETED | Команда удалила бота, которому принадлежит это соединение |
| 4006 | MESSAGE_RATE_EXCEEDED | Бот прислал больше сообщений, чем позволяет лимит частоты; подключиться снова можно сразу |
| 4007 | PLATFORM_UPDATING | Платформа обновляется: подключитесь снова |
| 1009 | — | Сообщение бота длиннее 8 КиБ: сервер его не принимает и закрывает соединение |
| 1011 | — | Необработанная ошибка платформы при выполнении команды бота |

### Отказ в подключении

| HTTP | Значение | Смысл |
|---|---|---|
| 401 | BOT_TOKEN_INVALID | Подключение бота без действующего токена: токен не передан, не выпускался или перевыпущен |
| 403 | BOT_BLOCKED | Подключение заблокированного администратором бота с его действующим токеном |

### BetRejectionReason

Причина, по которой платформа не приняла ставку

| Значение | Смысл |
|---|---|
| BETTING_CLOSED | Ставка сейчас не принимается: бот не приглашён к ставке или время на ставку вышло |
| MODIFIER_NOT_AVAILABLE | На этот модификатор ставить нельзя: его нет в приглашении |
| INVALID_AMOUNT | Недопустимый размер ставки: не положительный или больше maxAmount из приглашения |

### Bonus

Бонус: действие бота в свой ход командой USE_BONUS

| Значение | Смысл |
|---|---|
| DISTANCE | «Расстояние»: расстояние от указанной клетки до ближайшей клетки непотопленного корабля соперника; нужна клетка, тратит выстрел из лимита |
| SONAR | «Сонар»: сколько клеток кораблей соперника в квадрате 3 × 3 с центром в указанной клетке; нужна клетка, тратит выстрел из лимита |
| SALVO | «Залп»: до конца хода 3 выстрела, попадание выстрел хода не тратит; выстрела из лимита не тратит |
| SHIELD | «Щит»: отбивает следующее попадание по флоту бота — результат DEFENDED; одновременно активен один щит; тратит выстрел из лимита |
| MINE | «Мина»: мина на клетке своего поля без корабля, по которой соперник ещё не стрелял; выстрел соперника в неё — результат MINE; нужна клетка, тратит выстрел из лимита |

### BonusRejectionReason

Причина, по которой платформа не применила бонус

| Значение | Смысл |
|---|---|
| NOT_YOUR_TURN | Не ход бота: ход соперника, партия ещё в расстановке или уже завершена |
| BONUS_NOT_AVAILABLE | Этого бонуса у бота в партии нет |
| BONUS_LIMIT_REACHED | Использования бонуса в партии кончились |
| BONUS_ALREADY_ACTIVE | Бонус уже действует: щит ещё не сработал или ход уже стал залпом |
| INVALID_CELL | Клетка не подходит бонусу: не указана или вне поля, а для мины ещё — с кораблём, уже обстрелянная соперником или с миной |

### BotCommandRejectionReason

Причина, по которой платформа отклонила команду бота

| Значение | Смысл |
|---|---|
| UNKNOWN_MODE | Режима с таким именем на платформе нет |
| NO_RUNNING_MATCH | У бота сейчас нет идущей партии: до первой партии или между партиями; во время торгов «Казино „Рояль“» партии ещё нет |
| UNREADABLE_MESSAGE | Сообщение не читается: не JSON или не JSON-объект |
| UNKNOWN_COMMAND | Поле type отсутствует или не называет известную команду |
| INVALID_COMMAND | Поля известной команды некорректны: отсутствуют, пустые, не того типа или вне диапазона |
| UNKNOWN_BUILT_IN_BOT | Встроенного бота с таким именем на платформе нет |

### BotCommandType

Вид команды бота — значение поля type

| Значение | Смысл |
|---|---|
| CHANGE_MODE | Смена режима |
| PLACE | Расстановка кораблей |
| SHOOT | Выстрел |
| USE_BONUS | Применение бонуса |
| PLACE_BET | Ставка на модификатор |

### BotMode

Режим подключённого бота: в какие партии он попадает со следующего матча

| Значение | Смысл |
|---|---|
| RANKING | Рейтинговые бои с ботами других команд; режим только что подключённого бота |
| TRAINING | Тренировочные бои со встроенными ботами платформы |

### BuiltInBot

Уровень встроенного бота платформы — соперника в тренировочных боях; имя значения — идентификатор в поле opponent команды CHANGE_MODE, в API и в журнале партии

| Значение | Смысл |
|---|---|
| EASY | Лёгкий уровень; соперник по умолчанию в тренировке |
| MEDIUM | Средний уровень |
| HARD | Сложный уровень |

### MatchEndReason

Причина завершения партии

| Значение | Смысл |
|---|---|
| FLEET_DESTROYED | Все корабли одного из игроков потоплены |
| TIME_LIMIT | Вышло время партии; исход — по числу попаданий |
| SHOT_LIMIT | Оба игрока исчерпали лимит выстрелов; исход — по числу попаданий |
| NO_PLACEMENT | Техническое поражение: соперник не прислал корректную расстановку в окне расстановки |
| NEITHER_PLACED | Ни один игрок не прислал корректную расстановку в окне расстановки; победителя нет |
| SPEEDRUN_FINISHED | «Спидран» решён: побеждает потопивший флот за меньшее число выстрелов, при равном числе — ничья |

### PlayerKind

Тип игрока партии; значения добавляет каждый адаптер игрока

| Значение | Смысл |
|---|---|
| REMOTE_BOT | Бот команды, подключённый к платформе по WebSocket |
| BUILT_IN_BOT | Встроенный бот платформы; ссылка на игрока — уровень, имя значения BuiltInBot |

### PlayerOutcome

Итог партии для игрока

| Значение | Смысл |
|---|---|
| WIN | Победа |
| LOSS | Поражение |
| DRAW | Ничья |

### RejectionReason

Причина, по которой движок отклонил расстановку или выстрел

| Значение | Смысл |
|---|---|
| SHIP_NOT_STRAIGHT_LINE | Корабль пуст, его клетки повторяются или не лежат на одной прямой подряд |
| SHIP_OUT_OF_BOARD | Клетка корабля за пределами поля |
| FLEET_MISMATCH | Длины кораблей не совпадают с составом флота из набора правил |
| SHIPS_OVERLAP | Клетка принадлежит двум кораблям |
| SHIPS_TOUCH | Корабли касаются стороной или углом |
| PLACEMENT_ALREADY_ACCEPTED | Расстановка этого игрока уже принята и окончательна |
| NOT_YOUR_TURN | Выстрел не в свой ход |
| MATCH_FINISHED | Партия уже завершена |
| NO_PLACEMENT_IN_MATCH | В этой партии расстановки нет: флот расставляет платформа |

### RuleModifier

Модификатор правил партии; в партии действует не больше одного

| Значение | Смысл |
|---|---|
| DUEL | «Дуэль»: ход переходит к сопернику после каждого выстрела, даже после попадания |
| THREE_MUSKETEERS | «Три мушкетёра»: в ходе несколько выстрелов (shotsPerTurn); промах тратит выстрел хода, попадание — нет |
| SCHRODINGER_SHIP | «Корабль Шрёдингера»: потопление не объявляется — вместо SUNK приходит HIT стрелявшему, владельцу корабля и в MATCH_SNAPSHOT |
| HUNGER_GAMES | «Голодные игры»: лимит выстрелов на игрока снижен (shotLimitPerPlayer), исход чаще решает число попаданий |
| SPEEDRUN | «Спидран»: флот не расставляется — оба стреляют по копиям одной расстановки платформы, каждый в своём темпе, выстрелы соперника не приходят; побеждает потопивший флот за меньшее число выстрелов |
| BIRD_BOX | «Птичий короб»: бот не видит действий соперника по своему полю — OPPONENT_SHOT и OPPONENT_BONUS_USED не приходят, в MATCH_SNAPSHOT нет выстрелов соперника |
| OLD_SCHOOL | «Олдскул»: обычные правила без бонусов |
| CASINO_ROYALE | «Казино „Рояль“»: модификатор партии выбирают закрытые ставки ботов до её начала — от BET_REQUESTED до BETTING_FINISHED |

### ShotResult

Результат принятого выстрела

| Значение | Смысл |
|---|---|
| MISS | Мимо: клетка без корабля, вне поля или уже обстрелянная этим игроком |
| HIT | Ранил: у корабля остались целые клетки |
| SUNK | Убил: подбита последняя целая клетка корабля |
| DEFENDED | Отбито щитом: попадание не засчитано, клетка осталась необстрелянной, ход перешёл к владельцу щита |
| MINE | Выстрел в мину: засчитан, клетка обстреляна, попаданием не считается; ход перешёл к владельцу мины, следующий ход стрелявшего пропускается |

### TouchRule

Правило касания кораблей при расстановке

| Значение | Смысл |
|---|---|
| NO_TOUCHING_EVEN_DIAGONALLY | Корабли не касаются друг друга ни стороной, ни углом |

### TurnAfterHitRule

Правило очерёдности хода после попадания

| Значение | Смысл |
|---|---|
| SHOOTER_KEEPS_TURN | После попадания или потопления ход остаётся у стрелявшего |
| HIT_SPENDS_SHOT | Попадание тратит выстрел хода, как промах: при одном выстреле за ход ход переходит после любого выстрела |
