Публичные API: `/api/v1/bots/{id}/statistics?kind=ALL`, `kind=RANKING`, `kind=TRAINING`; `/api/v1/bots/{id}/journal?page=N`.

## Интерпретация

Рейтинг полностью объясняется положительным балансом Elo в тренировках. Согласно снимку документации от 10 октября 2026, тренировки меняют рейтинг с K=10, встроенные соперники имеют общий для всех команд меняющийся рейтинг. Высокая доля побед против HARD даёт положительное математическое ожидание до достижения соответствующего уровня Elo; одно лишь число матчей не гарантирует рост.

Нельзя заключить, что Stefan сильнее других команд: матчей против них нет. Нельзя восстановить алгоритм поиска и расстановки по агрегатам. API подробностей и журнала партии вернули UNAUTHORIZED; авторизованный доступ к записям завершённых партий нужен для анализа последовательности выстрелов, добивания, исключения ореолов и повторяемости расстановок.

Сырые данные сохранены в snapshot.json. Статистика и журнал согласованы по 125 завершённым матчам; последующий отдельный запрос уже показал 126 матчей и рейтинг 1678.90.
