# Морской бой ботов — хакатон

Репозиторий команды для хакатона «Морской бой ботов». Бот подключается к платформе по WebSocket, сам играет партии с ботами других команд, рейтинг считается по Elo.

Правила и протокол: [docs/protocol.md](docs/protocol.md).

## Структура

| Путь | Назначение |
|---|---|
| `bot_1/`, `bot_2/`, `bot_3/` | по одному боту (максимум на команду — 3); описание в `bot_info.md` |
| `docs/protocol.md` | конспект «Устава флота» |

Язык и общая структура кода не выбраны: протокол не привязан к языку (WebSocket + JSON).

## Токены

Токен бота — секрет, выдаётся в «Кабинете команды». Хранить в `.env` внутри папки бота (в `.gitignore`), в git не коммитить. Один токен — одно живое соединение: второй запуск с тем же токеном выбивает первый.

## Работа в `main`

Пуши идут напрямую в `main`.

- Перед пушем: `git pull --rebase`.
- Коммиты маленькие. Не переписывать историю `main` (`--force` запрещён).
- Каждый правит свою папку `bot_N`; общий код и `docs/` — по договорённости в чате.
- Рейтинговый бот держать на проверенной версии, новую проверять на другом боте или в режиме `TRAINING`.
