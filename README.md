# Морской бой ботов — хакатон

Репозиторий команды. Бот подключается к платформе по WebSocket, сам играет партии с ботами других команд, рейтинг считается по Elo.

- Платформа: <https://hackathon.no-offence.ru> (лидерборд, матчи, правила, «Кабинет команды», документация)
- Адрес бота: `wss://hackathon.no-offence.ru/api/v1/bots/connection`, заголовок `Authorization: Bearer <токен бота>`


Только стандартная библиотека; `git diff docs/platform` покажет, что изменилось.

## Что важно сверх «Устава флота»

Из документации; подробности в [guide.md](docs/platform/guide.md):

- **Модификаторы.** Администратор включает один из: `DUEL`, `THREE_MUSKETEERS`, `SCHRODINGER_SHIP`, `HUNGER_GAMES`, `SPEEDRUN`, `BIRD_BOX`, `OLD_SCHOOL`, `CASINO_ROYALE`. Что и когда включится, не объявляется; бот читает `rules.modifier` из `MATCH_STARTED`.
- **Бонусы.** `DISTANCE`, `SONAR`, `SALVO`, `SHIELD`, `MINE` — команда `USE_BONUS`. Число использований задаётся в «Кабинете команды»; каждое применение оплачивается рейтингом.
- **Ставки.** В `CASINO_ROYALE` модификатор выбирают торги (`BET_REQUESTED` → `PLACE_BET`); ставка списывается из рейтинга.
- **Тренировка.** `CHANGE_MODE` с полями `mode` (`TRAINING` / `RANKING`) и `opponent` (`EASY` / `MEDIUM` / `HARD`).
- **Токен.** Один токен — одно соединение; перевыпуск токена и блокировка закрывают соединение. Токены ботов — в «Кабинете команды».

## Структура

| Путь | Назначение |
|---|---|
| `bot_1/`, `bot_2/`, `bot_3/` | по одному боту (максимум на команду — 3); описание в `bot_info.md` |
| `seabattle/` | ядро платформы: протокол, состояние партии, раннер, WebSocket с переподключением. Стабильно, под версии ботов не правится |
| `strategies/` | сменные стратегии (`Strategy` из `seabattle/strategy.py`); новая версия бота = новая стратегия |
| `tests/` | тесты ядра и стратегий, фейковая платформа для партий целиком |
| `docs/platform/` | документация платформы в Markdown |
| `tools/` | вспомогательные скрипты (не код ботов) |

Язык — Python 3.13+, зависимости через `uv`.

## Запуск и проверки

```bash
uv sync
uv run python -m bot_1          # токен берётся из bot_1/.env
bot_1/run.sh                     # то же под caffeinate (Mac не уснёт) с перезапуском после падения
uv run pytest && uv run ruff check seabattle strategies bot_1 tests && uv run mypy
```

Ctrl+C или SIGTERM: бот доигрывает идущую партию (до 240 с) и выходит; повторный сигнал останавливает сразу.

Настройки (в `bot_1/.env` или окружении): `TOKEN` (обязательно), `BOT_MODE` (`TRAINING` по умолчанию | `RANKING`), `BOT_OPPONENT` (`EASY` | `MEDIUM` | `HARD`, только для тренировки), `BOT_MATCHES` (сыграть столько партий и выйти самому; пусто — без предела), `BOT_URL`, `LOG_LEVEL`. Режим отправляется при каждом подключении: новое соединение платформа начинает в `RANKING`.

## Токены

Токен бота — секрет. Хранить в `.env` внутри папки бота (в `.gitignore`), в git не коммитить и не вставлять в `bot_info.md`.

## Работа в `main`

Пуши идут напрямую в `main`.

- Перед пушем: `git pull --rebase`.
- Коммиты маленькие. Не переписывать историю `main` (`--force` запрещён).
- Каждый правит свою папку `bot_N`; общий код и `docs/` — по договорённости в чате.
- Рейтинговый бот держать на проверенной версии, новую проверять на другом боте или в режиме `TRAINING`.
