# hard-quadrants-v1: оптимизация поиска катеров

Гипотеза: у HARD один катер в каждой четверти поля. До реализации изучены 29 прошлых HARD: 88 раскрытых катеров, повторов четверти среди них нет. В 13 полностью раскрытых полях — ровно один в каждой четверти. Нераскрытые корабли поражений неизвестны, поэтому это наблюдаемый шаблон, а не гарантия платформы.

## Что изменено

Отдельная стратегия `hard-quadrants` сохраняет раннюю атаку `hard-edge`. После уничтожения многопалубных кораблей ищет только в четвертях, где катер ещё не найден. Точно считает совместимые расстановки катеров с учётом промахов, известных ореолов и запрета касания, в том числе между четвертями. Выбирает клетку с максимальной долей занятости; seed разрешает ничьи. Последний катер ищется только в оставшейся четверти.

Гипотеза применяется к обычному полю 10×10 с четырьмя катерами. При повторе четверти, несогласованном количестве катеров, отсутствии согласованных комбинаций или превышении бюджета подсчёта (80 мс / 12% дедлайна) включается прежняя hard-edge. Её собственный fallback на fleet-mc сохранён. Профиль и причины отражены в DECISION; результаты SUNK восстанавливают четверти при replay. Общая расстановка и default fleet-mc/MEDIUM сохранены.

## Проверки

Smoke прошёл: последний катер в неизвестной четверти, точные веса совместимых комбинаций, запрет касания через границу, исключение промаха, повтор четверти и исчерпание четверти; прежние WS/reconnect/JSONL/DuckDB проверки тоже прошли.

Локально, на 13 раскрытых полях с одинаковым seed=31: среднее до уничтожения всего флота **51.846 → 44.923** выстрела; среднее промахов фазы катеров **24.615 → 17.692**. Улучшение в 10/13 парах. Ранние последовательности до фазы катеров совпали. Максимум точного подсчёта — 0.494 мс. Это повтор на полях, из которых выявлена гипотеза; независимая боевая проверка ниже.

## Чередующаяся боевая проверка

Шесть TRAINING/HARD, по одному матчу в запуске. Порядок: новая/контрольная стратегия для seed 8310, затем 8311, затем 8312. Наши расстановки внутри каждой пары совпали — проверены хеши PLACE. Расстановки HARD сервер выбирал независимо, поэтому это не сравнение на одинаковых полях соперника. Все матчи — обычные правила, FLEET_DESTROYED. Код и параметры в серии не менялись. Числа рассчитаны из DuckDB после завершения процессов.

## Решение и следующая серия

Оставить hard-quadrants отдельной перспективной стратегией для HARD; hard-edge сохранить для контроля. Следующая проверка — более длинная серия новой стратегии, затем сравнение с контрольной. Default пока сохраняем. Клиенты отключены, новые матчи после шести проверочных не запускались.

```bash
uv run battleship-hack smoke
uv run battleship-hack run --strategy hard-quadrants --opponent HARD --matches 20 --max-seconds 4800 --experiment hard-quadrants-v1-hard-20
# Откат выбранной стратегии
uv run battleship-hack run --strategy hard-edge --opponent HARD --matches 1 --experiment hard-edge-control
```

Артефакты: `data/bot2/hard-quadrants-v1-local-check.json`, `data/bot2/hard-quadrants-v1-live-summary.json`, JSONL и снимки кода каждого из шести запусков.
